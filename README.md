### Experiment Tracker
A tool to log and compare machine learning experiments from any research project. A Python library records every run (parameters, code version, metrics and predictions), and a web app compares configurations side by side. Already in use in my research, where it reproduced earlier results exactly.

`Python` `pandas` `FastAPI` `PostgreSQL` `React` `TypeScript` `Docker` `GitHub Actions`
